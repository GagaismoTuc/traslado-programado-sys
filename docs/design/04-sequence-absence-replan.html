Sequence / absence re-planning

From Ausencia to an acknowledged route version

Five sequence views keep each interaction within the skill's five-lifeline limit. The route scope changes by release; infeasible output remains a Oficina decision.

01 / Register and request

Every absence write is audited before a re-sequence request is sent.

02 / Build the routing problem

Completed work stays fixed; children already on board remain tied to their vehicle.

03 / Validate before publication

Infeasible output is shown to the Oficina; manual edits are revalidated before an override can be offered.

04 / Publish and nudge

Approval persists version N+1 and its audit record before an asynchronous push nudge.

05 / Acknowledge and report status

The Oficina can identify Choferes who have not acknowledged the current version.
