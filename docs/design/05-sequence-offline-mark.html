Sequence / offline event

Save first; sync when connected

The driver app owns the IndexedDB queue. There is no Background Sync; device-local marks stay durable until server confirmation.

01 / Capture, sync and reconcile

One UUID supports safe retries; a moved Traslado is accepted and surfaced, not discarded.

02 / Recovery boundaries

A session expiry preserves the queue; a device-revocation response is the only described local wipe.

03 / Restore and close the day

After a server restore, phones re-send the day's marks; the local plan is cleared only after queue confirmation.
