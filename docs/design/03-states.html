State machines / execution

Which transitions are allowed?

Traslado status and Recorrido status are separate server-side machines. The phone's pending-sync marker is a local overlay, not another server state.

Traslado

A Traslado may move to another Recorrido only while Planificado (before Subió).

Recorrido

Each publication creates the next version; closing is gated by all onboard Traslados reaching Entregado.
