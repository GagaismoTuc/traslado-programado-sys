State machines / execution

Which transitions are allowed?

Traslado status and Recorrido status are separate server-side machines. The phone's pending-sync marker is a local overlay, not another server state.

Traslado

A Traslado may move to another Recorrido only while Planificado. Corrections append a new event and preserve the original Marca.

Recorrido

Recorrido has four states; publishing N+1 updates a version attribute on Publicado or En curso.
